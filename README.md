# João Pedro Oliveira

Product Designer and Design Engineer with 8+ years in design. I design in Figma and build interfaces in React and TypeScript, working with AI agents (Claude Code). I'm studying Information Systems at ICMC-USP, in São Carlos, Brazil.

## What I'm working on

**dbflows**, a visual flow editor for WhatsApp and Blip chatbots that I created and lead at Digitalbot, beyond my UX/UI role. AI agents write the code; I decide what gets built and review every change before it ships. In a timed test with the same content, building a flow in dbflows was 3.7× to 6.5× faster than in Figma (authoring mechanics only). The code belongs to the company, so it isn't public.

**SuperCondo**, a condominium management SaaS for Brazil that I'm building with a partner. We did the research and discovery together; I designed the resident app in Figma, and my partner designed the building manager app and the extra components. I handle the engineering, from the Cloudflare setup (Workers, D1, R2, Queues) to the API and the two PWAs, one for residents and one for building managers, working with AI agents (Claude Code). First production release in September 2026; the pilot with the first condominium comes next.
